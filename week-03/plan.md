# 데스크톱 펫 계획서

## 만들 것
- 화면 오른쪽 아래 구석에서 내 타자에 맞춰 움직이는 키보드 로봇 펫
- 펫 그림은 `art/sheet.png` (1254×1254, 배경 투명, 2×2 칸에 포즈 4개)

| 칸 | 그림 | 언제 보여 주나 |
|---|---|---|
| 왼쪽 위 | 두 손을 듦 | 쉬기: 키를 1초 동안 안 누르면 |
| 오른쪽 위 | 왼손 키보드 · 오른손 듦 | 타자 ①: 키를 누를 때마다 ②와 번갈아 |
| 왼쪽 아래 | 두 손 키보드 · 한 손 흔듦 | 타자 ②: 키를 누를 때마다 ①과 번갈아 |
| 오른쪽 아래 | 자는 모습 (zzz) | 자기: 키를 30초 동안 안 누르면 |

- 펫 크기는 150px, 작업 표시줄 바로 위에 둔다.
- 펫 아래에 "오늘 1,234타" 처럼 누른 횟수를 보여 준다. 프로그램을 끄면 0부터 다시 센다.
- 마우스로 끌면 옮겨지고, 오른쪽 클릭 메뉴에서 "끄기"를 누르면 꺼진다.
- 창은 테두리가 없고, 배경이 투명하며, 항상 다른 창 위에 뜬다.

## 어디서 돌아가는지
- 내 컴퓨터 (Windows) 바탕화면
- 만드는 동안에는 `week-03/.venv` 의 Python 으로 `pet.py` 를 실행한다.
- 다 만들면 PyInstaller 로 묶은 `pet.exe` 하나를 더블클릭해서 실행한다.
- 컴퓨터를 켤 때 자동으로 실행하지는 않는다.

## 재료
| 재료 | 하는 일 |
|---|---|
| Python 3.15 (이미 설치됨) | 펫 프로그램 언어 |
| PySide6-Essentials | 투명하고 테두리 없는 펫 창, 오른쪽 클릭 메뉴 |
| pynput | 다른 창에서 타자를 쳐도 키 누름을 알아채기 |
| Pillow | `sheet.png` 를 포즈 4장으로 자르기 |
| PyInstaller | `pet.exe` 하나로 묶기 |

- 4가지 모두 `week-03/.venv` 가상환경에만 설치한다. 컴퓨터 전체 Python 은 건드리지 않는다.

## 단계

### 단계 0 · 계획서
- 할 일: 이 계획서를 쓴다.
- 확인할 것: 만들 것 · 시간 · 위치 · 조작이 내가 고른 대답과 같은지 읽어 본다.
- 커밋: `week-03 데스크톱 펫 계획서 추가`

### 단계 1 · 준비
- 할 일: `.venv` 를 만들고 재료 4가지를 설치한다. 설치하기 전에 허락을 받는다. `requirements.txt` 에 재료 목록을 적고, `.gitignore` 에 `.venv/` · `build/` · `dist/` · `*.spec` 을 넣어 GitHub 에 올라가지 않게 한다.
- 확인할 것: 재료 4가지를 불러오는 데 오류가 나지 않는지. Python 3.15 가 새 버전이라 PySide6 설치가 안 될 수 있다. 안 되면 거기서 멈추고 어떻게 할지 다시 정한다.
- 커밋: `week-03 펫 준비: 재료 목록과 .gitignore`

### 단계 2 · 그림 자르기
- 할 일: `cut.py` 로 `sheet.png` 를 4칸으로 잘라 `art/rest.png` · `art/type1.png` · `art/type2.png` · `art/sleep.png` 로 저장한다. 칸마다 둘레의 빈 곳을 똑같이 잘라 내서, 포즈가 바뀌어도 로봇이 흔들리지 않게 한다.
- 확인할 것: 그림 4장을 열어서 안테나 · 손 · 키보드 · zzz 가 잘리지 않았는지, 4장 크기가 같은지 본다.
- 커밋: `week-03 펫 그림을 포즈 4장으로 자름`

### 단계 3 · 펫 창 띄우기
- 할 일: `pet.py` 로 쉬는 포즈 하나만 화면 오른쪽 아래, 작업 표시줄 위에 150px 크기로 띄운다. 끌어서 옮기기와 오른쪽 클릭 "끄기"를 넣는다.
- 확인할 것: 로봇 둘레에 네모 배경이 없는지, 다른 창을 눌러도 펫이 위에 있는지, 끌면 옮겨지는지, "끄기"를 누르면 작업 관리자에서도 꺼졌는지 본다.
- 커밋: `week-03 펫 창 띄우기: 오른쪽 아래, 끌어서 옮기기, 끄기`

### 단계 4 · 타자에 맞춰 움직이기
- 할 일: pynput 으로 키 누름을 듣고 횟수만 1씩 더한다. 누를 때마다 타자 ①과 ②를 번갈아 보여 주고, 펫 아래에 "오늘 N타"를 표시한다.
- 확인할 것: 메모장 · 브라우저에서 칠 때도 펫이 움직이는지, 한글 입력 상태에서도 움직이는지, 10번 누르면 10타가 되는지 본다. 코드에서 어떤 키인지를 변수 · 파일 · 화면 어디에도 남기지 않는지 함께 읽어 본다.
- 커밋: `week-03 펫이 타자에 맞춰 움직이고 횟수를 셈`

### 단계 5 · 쉬기와 자기
- 할 일: 마지막으로 누른 뒤 1초가 지나면 쉬는 포즈로, 30초가 지나면 자는 포즈로 바꾼다. 다시 누르면 바로 타자 포즈로 돌아온다.
- 확인할 것: 시계를 보면서 1초와 30초에 포즈가 바뀌는지, 자다가 키를 누르면 깨는지 본다.
- 커밋: `week-03 펫 쉬기와 자기 추가`

### 단계 6 · exe 로 묶기
- 할 일: PyInstaller 로 그림까지 넣은 `pet.exe` 하나를 만든다. 검은 명령창은 뜨지 않게 한다.
- 확인할 것: `dist/pet.exe` 를 바탕화면 같은 다른 곳에 복사해서 더블클릭해도 그림이 나오고, 단계 3~5 확인이 똑같이 되는지 본다. 백신이 막으면 거기서 멈추고 이야기한다.
- 커밋: `week-03 펫 exe 묶는 방법 추가` (exe 는 올리지 않고, 묶는 명령만 남긴다)

## 하지 말 것
- 어떤 키를 눌렀는지 저장하거나 보내지 않는다. 파일 · 화면 · 로그 · 인터넷 어디에도 남기지 않고, 몇 번 눌렀는지만 센다.
- 누른 횟수도 파일에 저장하지 않는다. 프로그램을 끄면 사라진다.
- 인터넷에 연결하는 코드를 넣지 않는다.
- 컴퓨터를 켤 때 자동으로 실행되게 하지 않는다.
- `.venv` · `build` · `dist` · `pet.exe` 를 GitHub 에 올리지 않는다.
- 이번 주 재료 4가지 말고 다른 패키지를 설치하지 않는다. 필요하면 먼저 물어본다.
- 한 단계를 확인하고 커밋하기 전에는 다음 단계로 넘어가지 않는다.
- 원본 `art/sheet.png` 는 고치지 않는다.
