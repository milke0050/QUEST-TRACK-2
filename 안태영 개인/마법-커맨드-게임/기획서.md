# 영창술사 — 커맨드 마법 2D 액션 로그라이크 기획서 (v0.1)

> 지금 폴더에 있는 게임은 이 기획서를 바탕으로 만든 **플레이 가능한 프로토타입**이다.
> 원래 지시서는 "기획서 승인 후 개발"이었지만, 바로 만들어 달라는 요청에 따라 기획서와 프로토타입을 함께 만들었다.
> 기획서를 검토하면서 프로토타입을 직접 해 보고, 바꿀 점을 정하면 된다.

## 실행 방법
1. 이 폴더(`마법-커맨드-게임`)에서 `python -m http.server 8001` 실행
2. 브라우저에서 `http://localhost:8001` 열기
   (index.html 을 더블클릭해도 대부분 동작하지만, 서버로 여는 쪽이 안전하다)
3. 오류가 나면 화면 아래 빨간 줄에 표시된다. 자세한 내용은 F12 → Console.

## 1. 방향과 핵심 재미

**한 줄 요약**: "손으로 외운 커맨드를 위험 속에서 정확히 이어 치는 맛".

핵심 재미는 세 겹으로 쌓인다.
1. **손의 재미 (초 단위)** — ↓→ + Space 가 정확히 들어갈 때의 손맛. 실수 없이 넣으면 "완벽!" +10%.
2. **판단의 재미 (전투 단위)** — 지금 짧고 안전한 마법을 쓸지, 길고 강하지만 깨지기 쉬운 마법을 쓸지. 어떤 속성 순서로 이어서 복합 마법을 만들지.
3. **성장의 재미 (판 단위)** — 뽑기로 얻는 마법이 판마다 달라 빌드가 바뀌고, 숙련도는 판이 끝나도 남아 "내 손이 늘었다"를 느낀다.

**경계할 점**: 커맨드가 어렵기만 하면 진입 장벽이 된다 → 연습장, 지원병, 넉넉한 입력 판정, 숙련도로 완충한다.

## 2. 전체 시스템 구조

```
입력(키보드) ─▶ 커맨드 버퍼 ─▶ 커맨드 판정 ─▶ 영창(마법진) ─▶ 마법 발동 ─▶ 피해·상태이상·속성 상호작용
                    ▲                 │              │                 │
              영창 지원병        실패 피드백     피격 시 파괴?      다중 영창 사슬 ─▶ 복합 마법
                                                     │
                                                 페널티
런 구조: 타이틀 → 1~4층(웨이브 2개씩) → 방마다 보상 3택1(마법 뽑기/도구/지원병/체력) → 5층 밴시
메타: 기술 숙련도(브라우저 저장)
```

## 3. 마법 커맨드 시스템

### 방향 표기
숫자 패드 표기를 쓴다. `6`=→, `4`=←, `2`=↓, `8`=↑.
**커맨드에 대각선은 쓰지 않는다** (키보드로 넣기도 어렵고 인식도 불안정). 두 키를 같이 누르는 순간 생기는 대각선은 버퍼에 기록하지 않고 무시한다 → ↓↘→ 처럼 굴려도 ↓→ 로 인식된다.
**커맨드는 바라보는 방향과 상관없이 고정**이다(격투게임처럼 뒤집히지 않음). 외운 그대로 넣으면 된다. 마법은 캐릭터가 바라보는 쪽(가장 가까운 적 쪽)으로 나간다.

**키 나누기**: 마법 커맨드는 **화살표**, 이동은 **A/D**(S 웅크림), 대쉬는 **Shift**. 커맨드를 넣어도 캐릭터가 움직이지 않아서, 움직이면서 영창할 수 있다.

### 판정 방식 (`input.js`)
| 요소 | 값 | 이유 |
|---|---|---|
| 입력 버퍼 | 방향이 **바뀔 때마다** {방향, 시각} 기록, 최대 40개 | 같은 방향을 누르고 있는 것은 1번으로 친다. `→→`는 중간에 손을 떼야 2번 |
| 허용 시간 | `150 + 180 × 커맨드 길이` ms (첫 방향~마지막 방향) | 2칸 510ms, 4칸 870ms, 6칸 1230ms. 길수록 넉넉 |
| 마지막 입력 유예 | 마지막 방향을 뗀 뒤 300ms 안에 Space | 손을 살짝 먼저 떼도 성공 |
| 실수 허용 | 사이에 잘못된 방향 1개 (숙련도 Lv2부터 2개) | 손이 미끄러져 다른 방향이 한 번 끼는 경우 구제 |
| 우선순위 | 긴 커맨드부터 검사 | ↓→ 를 넣었는데 ↓ 마법이 나가는 문제 방지 |
| 선입력 | 영창 중 누른 Space 를 0.2초 기억 | 다중 영창을 끊김 없이 |
| 완벽 보너스 | 실수 0번 + 3칸 이상 → 위력 ×1.1 | 정확한 입력에 보상 |

### 실패 처리
- 위/아래가 섞인 방향을 2개 이상 넣고 Space 를 눌렀는데 맞는 마법이 없으면 **"커맨드 실패"**: 아무것도 안 나가고, 다중 영창 사슬이 끊긴다.
- 좌우만 누르며 Space → 실패가 아니라 기본 마력탄 (걷다가 쏘는 것을 실패로 치지 않기 위해).
- 연습장은 실패 이유를 알려 준다: "너무 느려요 (0.82초 / 허용 0.54초)", "순서가 달라요", "사이에 잘못된 방향이 2번".

### 커맨드 난이도 = 위력
커맨드 길이를 희귀도에 묶었다: 일반 1~2칸, 고급 2칸, 희귀 3~4칸, 영웅 5칸, 전설 6칸.

## 4. 희귀도별 마법 설계표

| 희귀도 | 확률 | 위력 | 커맨드 | 마나 | 영창 | 재사용 | 피격 시 파괴 | 파괴 페널티 |
|---|---|---|---|---|---|---|---|---|
| 일반 | 50% | ×1.0 | 1~2 | 8 | 0.12초 | 0.35초 | 30% | 1.0초 |
| 고급 | 28% | ×1.4 | 2 | 14 | 0.18초 | 0.6초 | 40% | 1.5초 |
| 희귀 | 14% | ×1.9 | 3~4 | 22 | 0.25초 | 1.0초 | 55% | 2.0초 |
| 영웅 | 6% | ×2.6 | 5 | 32 | 0.35초 | 1.8초 | 70% | 2.5초 |
| 전설 | 2% | ×3.5 | 6 | 45 | 0.45초 | 3.0초 | 85% | 3.0초 |

3층부터 영웅·전설 확률 2배.

**왜 이 수치인가**
- **마나 효율**(위력÷마나)은 일반 0.125, 전설 0.078 로 **희귀할수록 오히려 낮다**. 대신 한 방이 커서 짧은 기회(밴시 노출 8초)에 몰아치기 좋다. → "희귀=무조건 강함"을 막는다.
- **초당 위력**은 재사용 대기 때문에 전설도 일반의 약 1.5~2배 수준에서 멈춘다.
- **위험**: 영창이 길고 파괴 확률이 높아서, 적이 가까울 때 쓰면 손해. 실패하면 마나 45를 날리고 3초 취약.

### 마법 목록 (17종)
| 속성 | 일반 | 고급 | 희귀 | 영웅 | 전설 |
|---|---|---|---|---|---|
| 🔥 불 | 불씨 `↓` | 화염구 `↓→` | 화염 기둥 `→↓→` | 폭염진 `←↓→↓→` | 태양 낙하 `↓→↓→↑↑` |
| 💧 물 | 물방울 `←` | 물결 `↓←` | 소용돌이 `→↓←` | 빙결 해일 `→↓←↓←` | — |
| 🌪 바람 | 바람칼 `→→` | 회오리 `↓↑` | 질풍 베기 `→←→` | 대폭풍 `↓↑↓↑→` | — |
| ⚡ 전기 | 스파크 `↑` | 번개 강타 `→↓` | 연쇄 번개 `←→←→` | — | 뇌신의 심판 `→↓←→↑↑` |

### 속성의 장단점과 상호작용
| 속성 | 장점 | 단점 |
|---|---|---|
| 불 | 화상 지속 피해, 폭발 범위 | 젖은 적에게 ×0.75 |
| 물 | 범위·둔화·빙결, 전기와 시너지 | 단일 피해가 낮다 |
| 바람 | 가장 빠른 투사체, 관통, 밀치기, 돌진 무적 | 피해가 낮고 밀치면 다른 마법이 빗나갈 수 있음 |
| 전기 | 자동 조준, 연쇄, 감전 경직 | 고블린에게 내성, 보스는 경직 30%만 |

| 조합 | 효과 |
|---|---|
| 젖은 적 + ⚡ | 피해 ×1.5 (감전 증폭) |
| 언 적 + 🔥 | 피해 ×2 (융해) |
| 젖은 적 + 🔥 | 피해 ×0.75 (증발) — 일부러 손해. 대신 💧→🔥 은 복합 마법 '증기 안개' |
| 불타는 적 + 🌪 | 화상이 주변으로 번짐 |

## 5. 다중 영창 (복합 마법)

### 규칙
- 마법을 쓰고 **1.3초** 안에 다음 마법을 쓰면 사슬이 이어진다. 화면 아래에 "다음에 이 속성을 쓰면 무엇이 나가는지" 힌트가 뜬다.
- 사슬이 조합과 맞으면 **마지막 마법 대신 복합 마법**이 나간다(단순 연속 사용과 구분).
- 복합 마법 위력 = 재료 마법들 위력 배율의 평균 × 복합 마법 기본 피해 → 희귀한 마법·완벽 입력·숙련도가 복합 마법에도 반영된다.
- 위험: 마나 +8(2단)/+16(3단), 영창 시간 ×1.4, 마법진 파괴 확률 +15%p(2단)/+30%p(3단), 깨지면 페널티 ×1.5.
- 커맨드 실패나 피격으로 마법진이 깨지면 사슬이 끊긴다.
- **설계 규칙**: 3단 조합의 앞 두 개는 2단 조합과 겹치지 않게 한다 (겹치면 2단이 먼저 터져서 3단을 만들 수 없음).

### 조합표 (12종)
| 순서 | 이름 | 효과 |
|---|---|---|
| 🔥→🌪 | 화염 폭풍 | 크고 느린 불의 파도, 여러 번 타격 + 화상 |
| 💧→⚡ | 광역 감전 | 화면의 적 8명에게 번개 |
| 🌪→⚡ | 번개 폭풍 | 전방에 2.5초 번개 장판 |
| 💧→🔥 | 증기 안개 | 내 주변 둔화 장판 (방어용) |
| ⚡→🔥 | 플라즈마 창 | 무한 관통 고속 창 |
| 🌪→💧 | 폭우 | 화면 전체 물벼락 14번, 젖음·둔화 |
| 🌪→🌪 | 진공 칼날 | 무한 관통 + 강한 밀치기 |
| 💧→🌪→🔥 | 증기 폭발 | 큰 폭발 (희귀) |

## 6. 영창 지원병

- **Tab**: 도와줄 마법 고르기 (2칸 이상 마법만). **[ / ]**: 자동 비율 바꾸기.
- 지원병은 정해진 간격마다 커맨드 앞부분을 한 칸씩 "채워" 둔다. 화면에 초록(채움)·노랑(채울 예정)·흰색(내가 넣을 칸)으로 보인다.
- **마지막 칸은 항상 플레이어가 직접**: 자동 칸 수 = 반올림(비율 × (길이−1)).
- 직접 전부 입력해도 된다. 그때는 위력 100%.

| 자동 비율 | 위력 | 예: 뇌신의 심판(7칸)에서 내가 넣을 칸 |
|---|---|---|
| 0% | 100% | 7 |
| 25% | 95% | 5 |
| 50% | 85% | 4 |
| 75% | 70% | 3 |
| 100% | 60% | 1 |

**성장**: 자동 입력 간격 0.45 → 0.35 → 0.25 → 0.15초 / 다음 칸 크게 표시 / 지원 마법 마나 −8%씩(최대 3단계).
**밸런스 근거**: 지원 100% 의 위력 60%는 같은 마법을 직접 넣는 것보다 확실히 약하다. 대신 "완벽 보너스(+10%)"는 지원병을 쓰면 받을 수 없어서, 숙련자가 직접 넣으면 최대 1.1÷0.6 ≈ **1.8배** 차이가 난다. 지원병은 간격만큼 기다려야 해서 **연속 영창 1.3초 안에 쓰기 어렵다** → 복합 마법은 직접 입력하는 쪽이 유리하다.
**나중에 넣을 것**: 지원 마법 개수(슬롯) 늘리기 — 지금은 1개만 지원.

## 7. 보스: 밴시

| 단계 | 내용 | 공략 |
|---|---|---|
| 보호막 | 공중에 떠 있고, 본체 피해 15%만 들어감. 보호막 300 | **복합 마법 ×2.5**, 전기 ×1.3, 기본탄 ×0.4. 땅을 타는 물결·회오리는 닿지 않음 → 투사체·번개 위주 |
| 파괴 | 땅으로 떨어져 2.5초 휘청, **8초 마법진 노출** (피해 ×1.5) | 길고 강한 마법(영웅·전설)을 쓸 타이밍 |
| 복구 | 노출이 끝나면 2.5초 "마법진 복구" | 120 피해를 넣으면 **복구 실패 → 4초 더 노출**. 못 막으면 보호막 재생성 |
| 분노 | 체력 50% 이하 | 영혼탄 5발, 공격 간격 단축, 보호막 375, 저주 패턴 추가 |

| 패턴 | 예고 | 효과 | 대응 |
|---|---|---|---|
| 통곡 | 1.1초, 빨간 고리 + "숨을 들이쉰다" | 입력 버퍼 지움, 사슬 끊김, 영창 중이면 마법진 강제 파괴, 피해 6 | **Shift 대쉬(무적)로 피함**, 영창 보호 부적으로 마법진 보호, 또는 예고 중엔 짧은 마법만 |
| 영혼탄 | 0.6초 | 3발(분노 5발) 부채꼴 | 걷거나 회피 |
| 비명파 | 0.6초 | 땅을 타는 충격파 양쪽 | 회피로 통과 |
| 망령 소환 | 0.8초 | 박쥐 2마리 (잡몹 3마리 미만일 때만) | 💧→⚡ 광역 감전으로 정리 + 보호막도 깎음 |
| 저주의 속삭임 | 0.7초 (분노) | 느린 유도탄, 맞으면 5초 영창 시간 ×1.5 | 회피, 마법진 복구 도구로 해제 |

## 8. 마법진 파괴 페널티

**적용하는 것 (3개)**
1. 이미 낸 마나는 사라짐
2. 취약: 받는 피해 +30% (희귀도별 1~3초, 복합 마법이면 ×1.5)
3. 그 마법의 재사용 대기 + 같은 시간

**적용하지 않는 것**: 영창 속도 감소 — 밴시 저주에서만 쓴다. 페널티가 4개 다 겹치면 한 번 맞고 연달아 무너지는 "억울한 연쇄"가 생기기 때문.

**억울함 방지 장치**
- 모든 적 공격에 예고(빨간 빛, 글자). 밴시 통곡은 1.1초 예고.
- 맞은 뒤 0.9초 무적 → 한 번의 실수가 연속 피격으로 번지지 않음.
- 파괴 확률은 100%가 아니다(30~85%). 버티면 "마법진 버팀!" 표시, 경직 없이 영창 계속.
- Shift 대쉬로 영창을 **스스로 취소하면 페널티 없이 마나 절반 환불** → "위험하면 접는다"는 선택지.
- 영창 중 머리 위에 **파괴 확률이 표시**되어 위험을 알고 선택한다.

## 9. 기술 숙련도와 도구

### 숙련도 (판이 끝나도 유지, 연습장에서는 안 오름)
| 레벨 | 필요 사용 | 효과(누적) |
|---|---|---|
| Lv1 | 5번 | 위력 +3%, 마나 −5%, 허용 시간 +12%, 영창 −6% |
| Lv2 | 15번 | 위 효과 2배 + **실수 1번 더 허용** |
| Lv3 | 30번 | 위 효과 3배 |
| Lv4 | 60번 | 위 효과 4배 + **상태이상 시간 +50%** |

Lv4 최대치: 위력 +12%, 마나 −20%, 허용 시간 +48%, 영창 −24%.
**왜 이 정도인가**: 커맨드 자체는 줄지 않는다. 판정만 넉넉해져서 "손으로 넣는 재미"는 유지되고, 위력 증가는 +12%로 작아서 희귀도 한 단계(+40% 이상)를 넘지 못한다.
연습장에서 안 오르게 한 이유: 연습장 반복으로 숙련도를 쌓는 지루한 노가다를 막기 위해.

### 도구 (C 사용, V 바꾸기, 최대 5개, 처음에 물약·부적)
| 도구 | 효과 | 다중 영창과의 관계 |
|---|---|---|
| 🧪 마나 물약 | 마나 +50 | 3단 조합 마나 보충 |
| 📜 영창 보호 부적 | 10초 마법진 파괴 무효 | 통곡을 무시하고 전설 마법 |
| 🔧 마법진 복구 도구 | 취약·저주·재사용 대기 해제 | 파괴 직후 바로 복구 |
| 💨 순간 회피 장치 | 뒤로 순간이동 + 1.2초 무적 | 긴 영창 전에 거리 벌리기 |
| ⏳ 영창 모래시계 | 15초 허용 시간 ×1.6, 사슬 시간 ×1.5 | 3단 조합 연습·성공률 상승 |
| 💎 증폭 수정 | 다음 마법 ×1.6 | 복합 마법에 쓰면 최고 효율 |

## 11. 시스템 간 충돌과 밸런스 문제 — 그리고 개선안

| # | 문제 | 왜 문제인가 | 지금 적용한 해결 | 더 할 수 있는 것 |
|---|---|---|---|---|
| 1 | **커맨드 겹침** (`→↓→` 안에 `↓→`, `→↓` 다음 바로 `→`) | 의도하지 않은 마법이 나감 | 긴 커맨드 우선 + 허용 시간 제한 | 겹치는 마법을 같은 판에 같이 뽑히지 않게 하거나, 우선순위를 플레이어가 고르게 |
| 2 | **방향과 이동이 같은 키** | 커맨드를 넣으면 캐릭터가 움직임 | 커맨드는 화살표, 이동은 A/D, 대쉬는 Shift 로 키를 나눔 | 게임패드 지원 시 이동은 스틱, 커맨드는 D-패드로 나누는 옵션 |
| 3 | **자동 방향 전환** | 양쪽에 적이 있으면 앞/뒤가 갑자기 바뀌어 커맨드가 뒤집힘 | 커맨드를 방향과 상관없이 고정 (v0.4). 남은 문제: 마법이 어느 쪽으로 나갈지 헷갈릴 수 있음 | 방향 전환에 0.15초 지연, 또는 "방향 고정" 키 |
| 4 | **2단 조합이 3단 조합을 막음** | 💧→🌪 가 2단이면 💧→🌪→🔥 를 영원히 못 씀 | 3단의 앞 두 개는 2단과 겹치지 않게 설계 | 데이터 검사 코드로 자동 확인 |
| 5 | **지원병 + 복합 마법 = 너무 쉬움?** | 지원 100% 로 마지막 칸만 눌러 3단 조합을 계속 쓰면 숙련 의미가 없어짐 | 위력 60% + 자동 입력에 시간이 걸려 1.3초 사슬 안에 쓰기 어려움 + 완벽 보너스 없음 | 지원병으로 만든 사슬은 복합 마법 위력 추가 −10% |
| 6 | **전기 + 물 빌드가 지배적** | 젖음 ×1.5 + 광역 감전 + 보호막 ×1.3 → 전기만 쓰면 됨 | 전기 내성 적(고블린), 보스 경직 30% | 보스 2에서 전기 보호막(전기 ×0.5) 같은 "카운터 보스" 추가 |
| 7 | **바람 밀치기가 다른 마법을 방해** | 밀쳐낸 적이 화면 밖으로 → 화염 기둥·장판이 빗나감 | 골렘은 밀치기 40%만, 장판·폭발은 적 위치를 노림 | 벽에 부딪히면 추가 피해 (밀치기를 장점으로) |
| 8 | **전설 마법의 고위험이 너무 큼** | 85% 파괴 + 3초 취약이면 보스전에서 아예 안 쓰게 됨 | 노출 중 보스는 공격 간격 ×1.4로 느려짐 → 쓸 타이밍이 생김. 부적으로 무효 | 테스트 후 전설 파괴 확률 70%로 내리기 검토 |
| 9 | **마나 고갈 뒤 할 게 없음** | 기본 마력탄만 쏘는 지루한 구간 | 마나 회복 9/초, 기본탄 마나 0 | 적 처치 시 마나 조각 드롭 |
| 10 | **숙련도 영구 성장 → 뒤로 갈수록 너무 쉬워짐** | 로그라이크 긴장감 감소 | 효과 상한이 작음 (+12%) | 승리 후 "난이도 단계(어센션)" 추가 |
| 11 | **통곡이 지원병 진행도도 지워야 하나?** | 지금은 버퍼만 지우고 지원병 칸은 남음 → 지원병이 통곡 대책이 됨 | 그대로 둠 (지원병의 장점) | 테스트 후 결정 |
